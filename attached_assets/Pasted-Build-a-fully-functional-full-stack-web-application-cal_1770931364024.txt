Build a fully functional full-stack web application called InternOps, a global platform for managing interns.

Use:

- Backend: Node.js + Express.js
- Database: SQLite
- Authentication: JWT + bcrypt
- Frontend: HTML/CSS/JS (minimal, clean, professional)
- Modular architecture

# 3. SIGNUP FLOW

- Signup button → choose role: Manager | Intern
- Manager signup:
    - Enter name + email
    - Status = pending_admin_approval
    - Admin approves → system generates password → email credentials
- Intern signup:
    - Enter name + email
    - Status = pending_manager_approval
    - Manager approves → generate password → email sent
- Remove public signup for admin
- Add login hints/placeholders for all roles

---

# 4. LOGIN SYSTEM

- Separate login pages for admin, manager, intern
- JWT authentication + secure sessions
- Redirects after login:
    - admin → admin-dashboard.html
    - manager → manager-dashboard.html
    - intern → intern-dashboard.html
- Admin login hints:
    - Email: "Admin email (example: nifraz)"
    - Password: "Admin password"
- Manager login hints:
    - Email: "Manager email (sent after admin approval)"
    - Password: "Password received via email"
- Intern login hints:
    - Email: "Intern email (approved by manager)"
    - Password: "Password sent to your email"

# 8. DATABASE STRUCTURE

Users table:

- id
- name
- email (unique)
- password_hash
- role ("admin","manager","intern")
- created_by (id of creator)
- assigned_manager_id (for interns)
- created_at

SignupRequests table:

- id
- name
- email
- requested_role
- status ("pending", "approved", "rejected")
- requested_to (admin or manager)
- created_at

Tasks table:

- id
- title
- description
- created_by (manager id)
- assigned_to (intern id)
- status ("pending","in progress","completed")
- created_at
