Build a fully functional, full-stack web application called InternOps. It is a global platform for managing interns, managers, and companies. Make it investor-ready and fully functional.

Use:

- Backend: Node.js + Express.js
- Database: SQLite (scalable multi-company design)
- Authentication: JWT + bcrypt
- Frontend: HTML/CSS/JS (clean, minimal, professional)
- Modular architecture

# 3️⃣ LANDING PAGE

- Clean, minimal, professional
- App name: InternOps
- Tagline: "Manage interns, tasks, and AI collaboration seamlessly"
- Two main centered buttons:
    1. **Login** → opens modal/page with three role options: Admin, Manager, Intern
        - Each redirects to respective login page
        - Login hints:
            - Admin: Email "Admin email (example: nifraz)", Password "Admin password"
            - Manager: Email "Manager email (sent after admin approval)", Password "Password received via email"
            - Intern: Email "Intern email (approved by manager)", Password "Password sent to your email"
        - Show status indicators: Pending, Approved, Rejected
    2. **Sign Up** → opens modal/page with two role options: Manager, Intern
        - Each role shows role-specific signup form (Name + Email)
        - Manager signup → admin approval
        - Intern signup → manager approval
        - Helper text explaining approval process
- Fully mobile-friendly
- No extra widgets, ads, or clutter

# 9️⃣ DATABASE STRUCTURE

## Users table

- id
- name
- email (unique)
- password_hash
- role ("admin","manager","intern")
- created_by
- assigned_manager_id (for interns)
- company_id
- created_at

## SignupRequests table

- id
- name
- email
- requested_role
- status ("pending","approved","rejected")
- requested_to (admin/manager)
- company_id
- created_at

## Tasks table

- id
- title
- description
- created_by (manager id)
- assigned_to (intern id)
- status ("pending","in progress","completed")
- start_date
- end_date
- created_at
